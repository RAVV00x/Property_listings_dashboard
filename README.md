# Property Listings Dashboard

## Project Overview
This project analyzes property listings using Tableau to understand property prices, locations, and listing distributions.

## Objectives
- Analyze property prices across different cities.
- Compare the number of property listings.
- Understand price distributions.
- Identify trends and patterns in property listings.

## Tools Used
- Tableau
- Microsoft Excel

## Dashboard Features
- Key Performance Indicators (KPIs)
- Number of Listings by City
- Price Comparison by City
- Area vs Price Analysis
- Property Price Distribution

## Files Included
- Property_Dashboard.twbx – Tableau dashboard.
- Dataset.xlsx – Dataset used for analysis.
- Dashboard_Screenshot.png – Dashboard preview.

## How to View
Download the Tableau packaged workbook (.twbx) and open it using Tableau Desktop.
